# SQL injection lab

Учебный скрипт на Python, который показывает, как параметризованный запрос
защищает форму входа от SQL-инъекций. Скрипт создаёт базу SQLite в памяти
с двумя пользователями и пробует войти с обычными данными и с типичными
инъекциями в поле логина.

## Запуск
```
uv run python src/sql_injection_lab/lab.py
```
Аргументов нет: пользователи и тестовые логины заданы в коде. База создаётся
в памяти и исчезает после завершения скрипта.

## Что проверяется
| Логин | Пароль | Что это значит | Результат |
|---|---|---|---|
| `alex` | `pass123` | верные данные | вход разрешён |
| `alex` | `wrong` | неверный пароль | отказ |
| `alex'` | `x` | кавычка ломает строку в уязвимом запросе | отказ |
| `alex' --` | `anything` | комментарий отрезает проверку пароля | отказ |
| `alex' OR 1=1 --` | `anything` | условие, которое всегда истинно | отказ |
| `nobody' OR 1=1 --` | `x` | вход без существующего логина | отказ |

## Пример вывода
```
[(1, 'alex'), (2, 'admin')]
SELECT id FROM users WHERE username = ? AND password = ?
alex pass123 True
SELECT id FROM users WHERE username = ? AND password = ?
alex wrong False
...
SELECT id FROM users WHERE username = ? AND password = ?
alex' OR 1=1 -- anything False
SELECT id FROM users WHERE username = ? AND password = ?
nobody' OR 1=1 -- x False
```
Первая строка это содержимое таблицы, дальше для каждой попытки печатается
запрос и результат: логин, пароль и `True`, если вход разрешён.

## Как это работает
1. Скрипт создаёт в памяти таблицу `users` с пользователями `alex` и `admin` и выводит её содержимое.
2. Функция `login` выполняет запрос с плейсхолдерами `?`, а логин и пароль передаёт отдельно. SQLite подставляет их как значения, а не как часть SQL, поэтому кавычки, `--` и `OR 1=1` ищутся в базе как обычный текст.
3. Вход разрешён, только если запрос вернул хотя бы одну строку. Поэтому срабатывает только пара `alex` / `pass123`, а все инъекции получают отказ.
4. Если собрать запрос через f-строку (`f"... WHERE username = '{username}' ..."`), те же логины с `--` и `OR 1=1` пропустят без пароля. Именно эту разницу и показывает лабораторная.
