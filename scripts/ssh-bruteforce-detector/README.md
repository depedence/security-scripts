# SSH brute-force detector

Скрипт на Python, который ищет в логе SSH признак успешного подбора пароля:
IP-адрес, с которого сначала было много неудачных попыток входа,
а потом успешный вход. Результат выводится на экран и записывается в `report.txt`.

## Запуск
```
uv run python src/ssh_bruteforce_detector/detect.py data/auth_sample.txt 3
```
Первый аргумент это файл лога, второй порог: сколько неудачных попыток
до успешного входа считать подбором пароля. Файл `report.txt` создаётся в папке,
откуда запущен скрипт, и перезаписывается при каждом запуске.

## Что это находит
| Ситуация в логе | Попадает в отчёт |
|---|---|
| 5 неудачных попыток, затем успешный вход с того же IP | да, при пороге 5 и меньше |
| 2 неудачные попытки, затем успешный вход, порог 3 | нет |
| Много неудачных попыток, но входа так и не было | нет |
| Успешный вход без единой неудачи | нет |
| Неудачные попытки только после успешного входа | нет |

## Пример данных
```
Nov  4 10:02:03 srv sshd[1203]: Failed password for admin from 198.51.100.7 port 40320 ssh2
...
Nov  4 10:02:31 srv sshd[1203]: Failed password for admin from 198.51.100.7 port 40324 ssh2
Nov  4 10:03:40 srv sshd[1207]: Accepted password for alex from 198.51.100.7 port 40322 ssh2
```

## Пример вывода
```
198.51.100.7: 5
```
В отчёт попадает IP и число неудачных попыток до успешного входа.

## Как это работает
1. Скрипт читает лог построчно, строки без слова `from` или с обрывом после него пропускаются. IP это слово сразу после `from`, поэтому разбор работает и для строк вида `invalid user guest from ...`.
2. Для строк `Failed` скрипт увеличивает счётчик неудач для этого IP.
3. Когда встречается строка `Accepted`, скрипт смотрит, сколько неудач у этого IP накопилось до неё. Если не меньше порога, IP попадает в результат. Лог читается по порядку, поэтому неудачи после входа не считаются.
4. Скрипт проверяет аргументы: без файла или порога, с нечисловым порогом или с несуществующим файлом он выводит понятное сообщение и завершается без ошибки Python.
