# Web log analyzer

Скрипт на Python, который разбирает лог веб-сервера и показывает:
сколько было ответов с каждым кодом, какие IP похожи на сканеры
(много ответов 404) и какие запросы содержат признаки атак
(SQL-инъекции, path traversal, XSS).

## Запуск
uv run python src/web_log_analyzer/analyze_web.py data/access.log 3

## Что это находит
| Шаблон в URL | Что это значит |
|---|---|
| union | попытка SQL-инъекции (UNION SELECT) |
| 1=1 | SQL-инъекция: условие, которое всегда истинно |
| ../ | path traversal: выход из папки к чужим файлам |
| <script | XSS: вставка скрипта на страницу |

## Пример вывода
```
Status codes:
200: 6
404: 5
403: 1
401: 2
Scanners (3+ x 404):
203.0.113.7: 5
Suspicious requests:
198.51.100.23 /products?id=1+UNION+SELECT+username,password+FROM+users
198.51.100.23 /products?id=1+OR+1=1
192.0.2.55 /download?file=../../etc/passwd
192.0.2.55 /search?q=<script>alert(1)</script>
```

## Как это работает
1. Скрипт идёт по лог-файлу построчно, и из каждой строки достаёт IP, URL и код ответа по их позициям после split(). Битые короткие строки пропускаются.
2. Коды ответов считаются в словаре, а ответы 404 считаются отдельным словарём по IP. Если у IP их не меньше порога, он попадает в «сканеры».
3. URL приводится к нижнему регистру и сравнивается со списком шаблонов атак. Каждый подозрительный запрос попадает в список один раз.
