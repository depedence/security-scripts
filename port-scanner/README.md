# Port scanner

Скрипт на Python, который проверяет диапазон TCP-портов на указанном хосте
и выводит, какие из них открыты. Порт считается открытым, если к нему
удалось установить TCP-соединение.

## Запуск
```
uv run python src/port_scanner/scanner.py 127.0.0.1 8000 8010
```
Первый аргумент это хост (IP или имя), второй и третий начало и конец
диапазона портов, оба включительно.

Для проверки есть тестовый HTTP-сервер, который слушает `127.0.0.1:8005`:
```
python tools/server.py
uv run python src/port_scanner/scanner.py 127.0.0.1 8000 8010
```

## Что это находит
| Ситуация на порту | Попадает в отчёт |
|---|---|
| Сервис принимает TCP-соединение | да, как `open` |
| Порт закрыт, соединение отклонено | нет |
| Ответа нет за 1 секунду (порт фильтруется firewall) | нет |
| UDP-сервис | нет, проверяется только TCP |

## Пример вывода
```
Scanning 127.0.0.1 ports 8000-8010
8005: open
Done: 1 open
```
Закрытые порты не выводятся, в конце печатается число открытых.

## Как это работает
1. Скрипт проверяет аргументы: если их меньше трёх, порты не числа или начало диапазона больше конца, он выводит понятное сообщение и завершается с кодом 1.
2. Для каждого порта из диапазона по порядку вызывается `socket.create_connection` с таймаутом 1 секунда. Если соединение установилось, оно сразу закрывается, а порт записывается в результат как `open`.
3. Любая ошибка соединения (`OSError`: отказ, таймаут, неизвестный хост) означает, что порт не открыт. Поэтому неверное имя хоста не роняет скрипт, а просто даёт `Done: 0 open`.
4. Порты проверяются последовательно, так что каждый закрытый без ответа порт добавляет до секунды ко времени сканирования.
